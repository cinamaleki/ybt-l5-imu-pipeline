# پایپ‌لاین YBT–L5

این مخزن نمونه‌کار پژوهشی سینا ملکی برای تحلیل IMU کمری حین آزمون Y-Balance است. کد بررسی کیفیت سیگنال، پیشنهاد بازیابی مرز حرکت، استخراج ویژگی و ارزیابی مدل با کنارگذاشتن کامل فرد آزمون را ارائه می‌کند.

**وضعیت:** نسخهٔ پژوهشی 0.1.0؛ تحلیل اکتشافی هفت نفر. ابزار تشخیص بالینی یا پیش‌بینی آسیب نیست.

## اجرا

پس از نصب Python و دریافت مخزن، در پوشهٔ پروژه اجرا کنید:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux / macOS instead: source .venv/bin/activate
python -m pip install .
ybt-l5 demo --output-dir demo_output
python -m unittest discover -s tests -v
```

فایل `demo_output/SYNTHETIC_REPORT.html` گزارش اجرای نمونه است. تمام سیگنال‌ها و مسافت‌های این نمونه مصنوعی‌اند و عملکرد آن نشان‌دهندهٔ عملکرد پژوهش واقعی نیست.

## نتایج واقعی چه می‌گویند؟

در ۱۴ ضبط، ۱۹۸ بازه با مرز ثبت‌شده و ۵۴ بازهٔ پیشنهادی داریم. بازیابی در آزمون پنهان‌کردن مارکر، ۱۶۰ بازه از ۱۹۸ بازه را با IoU حداقل ۰٫۵ تطبیق داد. حذف درست پالس مصنوعی اضافه فقط ۵۵٪ بود؛ بنابراین بازه‌های بازسازی‌شده همچنان نیازمند بررسی هستند.

در تحلیل اصلی، دقت متوازن مدل جهت با رگرسیون لجستیک ۳۶٫۵٪ و جنگل تصادفی ۳۹٫۷٪ بود؛ مبنا ۳۳٫۳٪. خطای میانگین فردی برآورد هم‌زمان مسافت نرمال‌شده از ۱۰٫۱۰ به ۸٫۶۱ واحد درصد رسید. این نتایج روی همین پایلوت کوچک به دست آمده‌اند و اعتبارسنجی مستقل ندارند.

چرخهٔ شش حالت سه بار تکرار شده است: راست ANT، چپ ANT، راست PM، چپ PM، راست PL، چپ PL. راست و چپ به پای اتکا اشاره دارند. آخرین عبارت «چپ PM» در پیام بعدی، مطابق ترتیب قبلی «چپ PL» تفسیر شده؛ نتایج وابسته به برچسب مشروط به این تفسیرند. سابجکت ۳ در گروه ۲ و سابجکت ۴ در گروه ۱ است.

## چه چیزی عمومی می‌شود؟

کد، روش‌ها، نتایج تجمیعی، تست‌ها و مولد دادهٔ مصنوعی. سیگنال واقعی، اکسل نمره‌ها، ویژگی و پیش‌بینی فردی، و نمایشگر حاوی دادهٔ واقعی عمومی نمی‌شوند. فایل `.gitignore` و بررسی درخت انتشار از ورود ناخواستهٔ این فایل‌ها جلوگیری می‌کنند؛ این بررسی جای بررسی انسانی را نمی‌گیرد.

راهنمای نصب کامل در [README](README.md)، توضیح علمی در [روش‌ها](docs/METHODS.md) و مراحل ساخت مخزن در [راهنمای GitHub](docs/GITHUB_SETUP.md) موجود است. مجوز پیشنهادی کد MIT است؛ شامل داده‌های شرکت‌کنندگان نمی‌شود.
